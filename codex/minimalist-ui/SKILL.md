# Editorial minimalist UI preset

Use when the brief calls for a restrained, editorial or document-like interface. This is a style direction, not a universal frontend rule. Preserve an existing brand and design system unless changing them is requested.

- Start with readable typography and generous but purposeful spacing. A warm white canvas, charcoal text, subtle dividers, and muted accents are useful defaults; preserve semantic colors and contrast.
- Contrast a clear body face with an editorial heading face when suitable. Use fonts actually available with appropriate licensing and script coverage. Existing system fonts and icon libraries are acceptable.
- Favor simple surfaces and content-led layouts. Use a grid only when the content benefits from one; choose radii, spacing, and border colors consistently with the project's tokens.
- Keep controls legible and discoverable, including focus, pressed, disabled, and error states. Avoid decoration that disguises what is clickable.
- Motion is optional. Use subtle transitions to explain changes, preserve content visibility without animation, and respect reduced motion. No compulsory staggered reveal or ambient background effects.
- Use real supplied assets and content. Label mock data appropriately; do not fabricate real customers, quotes, metrics, or photographs of a specific person or property.

Inspect narrow and wide layouts, long text, contrast, focus, and the relevant interaction states. Judge the result by reading and task completion, not by compliance with exact pixel values.
