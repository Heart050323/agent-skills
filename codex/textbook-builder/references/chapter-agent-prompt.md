# 章執筆エージェントへの依頼文テンプレート

`{...}` を埋めて、サブエージェントを使える場合はその依頼文として渡す(使えない場合は、この手順を自分で章ごとに実行する)。1エージェントにつき 1〜2 章。並列で起動してよい
(各エージェントが書くのは自分の章のファイルだけなので衝突しない)。

---

あなたは大学の科目「{科目名}」の教科書(LaTeX、出版水準)の一部を執筆する。

## 担当
{章番号と章タイトル、対応する資料とページ範囲。例:
- ch05「リレーショナル代数」: `{資料フォルダ}/レジュメ/4.pdf` 全ページ、`5.pdf` p.1–5、ハンズオン `handson4.pdf`
}

## 場所
- 教科書フォルダ: `{教科書フォルダ}`(ここに chapters/, figures/, refs/, notes/ がある)
- 元の資料: `{資料フォルダ}`
- 抽出済みテキスト: `{教科書フォルダ}/work/extracted/<資料名>.txt`(ページ区切り "===== p.N =====")
- 全体の章立て: `{教科書フォルダ}/outline.md`(ほかの章との分担・重複を避けるために読む)
- 過去問のメモ: `{教科書フォルダ}/notes/notes-exams.md`(あれば。章末問題に出題傾向を反映する)

## 手順
1. `{教科書フォルダ}/STYLE.md` を読み、そのとおりに書く(図・裏取り・構成のルールはここにある。章ラベルは `\label{chap:chNN}`、他章参照は `第~\ref{chap:chNN}~章`)
2. 担当の PDF を **全ページを画像として見る**(20ページずつ `pages` を指定)。抽出テキストだけに頼らない。図・表・数式・例を把握する
3. `notes/notes-chNN.md` に講義内容を忠実に抽出する(スライドごと。例のテーブルや SQL も書き写す)
4. ネットで裏取りし、不足を補う(STYLE.md §5)。情報源を `refs/chNN.bib` に
5. 図を作る(STYLE.md §4)。TikZ は `figures/chNN-*.tex`、切り抜きは `figures/chNN-*.png`
6. `chapters/chNN.tex` を書く
7. 単独でコンパイルして確認する:
   ```
   bash ~/.codex/skills/textbook-builder/scripts/test_chapter.sh "{教科書フォルダ}" chNN
   ```
   `BUILD OK` になるまで直す。Overfull が多ければ直す。表示された PDF のページを画像として開いてで数ページ見て、図の崩れがないか確認する
8. 他の章のファイル・main.tex・STYLE.md は編集しない

## 返答
最後に次だけを短く報告する(本文は返さない):
- 章タイトル、PDF ページ数(test_chapter の結果)、図の枚数(TikZ / 切り抜き)、章末問題数
- 裏取りで講義資料と食い違った点・補足した主な点
- 扱えなかった資料や気になる点

**本文の方針(最優先)**: `templates/STYLE.md` §0 を守る。本文に講義・資料・試験・過去問・年度・出典を書かない。問題の見出しは「演習: 内容」。資料の誤りは「よくある誤り」として一般的に書く。資料の出典やページは notes-chNN.md にだけ書く。
