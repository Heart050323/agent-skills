# 完成済みの本を新方針に書き直す手順

新方針は `templates/STYLE.md` §0(自己完結。元の授業・資料・試験の存在を本文に一切出さない)。
対象は `ナレッジまとめ/<科目>/`(QUEUE.md で [x] の出力先。`参考資料/` は対象外)。進み具合は `ナレッジまとめ/REWRITE.md` に記録する。

## 方針
- **中身は残す**: 説明・導出・図・例題・演習・補足は消さない。言い回しと構成だけを直す。ゼロから書き直さない
- 書き換えるのは本文: `chapters/*.tex`、`figures/*.tex`、`main.tex` の表紙の説明文(`\bookcover` の第 3 引数)、`refs/*.bib`。notes/ と work/ は内部メモなのでそのままでよい

## 1 冊の手順
1. **洗い出し**: 次の語を `chapters/ figures/ main.tex refs/` で検索し、該当箇所を一覧にする
   `講義 資料 スライド ノート 板書 教科書 担当 年度 旧課程 試験 過去問 期末 中間 出典 学生 シケプリ 解答例 レジュメ プリント 演習問題[`
   (「ESD 試験」「試験回路」「信頼性試験」など一般の用語は残してよい)
2. **本文の書き換え**:
   - 章冒頭・節冒頭の断り書き(「この章は講義では〜」「〇〇年度以前の範囲」「講義資料がないため標準文献で構成した」など)を削除する
   - 「講義では〜と説明された」→ 内容をそのまま地の文で書く。「講義資料 p.N の図」→ 図への参照だけにする
   - `chuui` の「資料の誤り」「解答例の誤り」「学生解答の誤り」→ 資料に触れず、「よくある誤り」として一般的に書き直す
     (正しい値・式だけを示し、「〜と書かれているが」とは書かない。定義の流儀の違いは一般論として残してよい)
   - `hosoku` の「講義にない内容」「講義では扱わない」→ 普通の補足として書く
   - 例題・章末問題の見出し「(出典: 2017 年度期末試験 問3)」→「演習: 内容の見出し」(reidai は内容の見出し)
   - 図のキャプションの「講義資料 第 N 回 p.M を描き直したもの」などを削除する。講義資料から切り出した PNG は TikZ で描き直すか、図ごと削除して本文を直す
3. **付録の作り直し**: 「過去問の解答・解説」を `references/appendix-guide.md` の「演習問題の解答と解説」に作り直す
   (分野別、年度・設問番号なし、年度別索引は削除、同じ問題はまとめる、本文で解いた問題は参照)。ラベル `chap:appendix-exams` は残す
4. **序文と表紙**: `chapters/preface.tex` を「本書のねらい・構成・読み方・枠の凡例・前提知識」で書き直す(資料と範囲の節は削除)。表紙の説明文も本の内容だけにする
5. **参考文献**: `refs/*.bib` から講義資料・講義ページ・学生のまとめのエントリを削除し、本文の `\cite` も消す
6. **確認**: もう一度 1 の語で検索し、元の資料・授業・試験を指す箇所が 0 になったことを確かめる
7. **ビルド**: fix_bib_names → fix_punct → `cat refs/*.bib > refs.bib` → build.sh。エラー・未定義参照・Overfull(>5pt)・ラベル重複・Missing character を 0 にし、pdftoppm -r 45 で数ページを目視する
8. **記録**: REWRITE.md(科目・状態・ページ数・直した箇所の数)と、その科目の PROGRESS.md の末尾に「新方針で書き直し済み(日付)」を書く

## 分担するとき
- 1 冊を章のまとまりで分けて並列に書き直してよい(各担当は自分の章のファイルだけ)。付録・序文・表紙・bib は最後に 1 人がまとめて直す
