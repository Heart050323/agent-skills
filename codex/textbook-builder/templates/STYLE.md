# 章執筆スタイルガイド(chapters/chNN.tex 用)

目標: **出版できる水準の、自己完結した教科書**。元の資料と問題の内容を一つ残らず取り込み、足りない説明は信頼できる情報源で補い、
前提知識のない読者がこの本だけで独学して理解できるようにする。

## 0. 本文の方針(最優先・2026-11-24 改訂)

本は、予備知識のない人がこの本だけを読んで内容を理解できる**自己完結した教科書**にする。元になった授業・資料・試験の存在を本文に一切出さない。

- **書かない言い回し**: 「講義では」「講義で扱わない」「講義にない内容を補足」「講義資料 p.N」「スライド」「ノート」「板書」「教科書 p.N」「担当教員」「〇〇年度の範囲」「旧課程」「試験」「過去問」「期末」「出典: 20XX 年度 問 N」「学生解答」「シケプリ」など、元の資料・授業・試験を指すもの(「ESD 試験」「試験回路」のような一般の用語は可)
- **演習**: 問題は「〜を理解するための演習」として出す。`mondai` の見出しは「演習: ガウシアンビームの広がり」のように内容を表すものにし、年度・設問番号・出典は書かない。同じ問題が何度も出ていれば 1 問にまとめる
- **誤り**: 元の資料にあった誤りは、資料に触れずに正しい内容だけを書く。間違えやすい点は `chuui` で「よくある誤り」として一般的に書く(「資料では〜と書かれているが」とは書かない)
- **補足**: `hosoku` は内容の補足(出典付き)として使う。「講義にない」とは書かない
- **参考文献**: 標準的な教科書・論文・規格・公式文書は参考文献に挙げてよい。講義資料・講義ページ・学生のまとめは挙げない
- **図**: 講義資料から画像を切り出さない(TikZ・pgfplots で描き直す)。キャプションに「講義資料を描き直したもの」などと書かない
- **序文・表紙**: preface は「本書のねらい・構成・読み方・枠の凡例・前提知識」だけ。表紙の説明文(`{{DESCRIPTION}}`)も本の内容だけを書く(「講義〇〇の資料と期末試験に基づく」と書かない)
- **作業メモは別**: notes/(notes-sources.md、notes-exams.md、notes-chNN.md)と work/ は作業用の内部メモなので、資料の出典やページを書いてよい。本文(chapters/・figures/・main.tex・refs/)に出さないことだけを守る
- 個人情報(学生の氏名・学籍番号、教員名・連絡先、パスワード、アカウント情報)は notes にも本文にも書かない。市販の教科書・解答集の文章・図・問題は転載しない


## 1. ファイルと置き場所

| 種類 | 置き場所 | 備考 |
|---|---|---|
| 章本文 | `chapters/chNN.tex` | `\chapter{...}` から始まる本文のみ。プリアンブル不要 |
| TikZ 図 | `figures/chNN-<名前>.tex` | `tikzpicture`(または `forest`)だけを書く。本文から `\input{figures/chNN-<名前>}` |
| 画像(スライド切り抜き等) | `figures/chNN-<名前>.png` | `crop_fig.py` で作る。本文から `\fig{chNN-<名前>}{0.7}{キャプション}{fig:chNN-<名前>}` |
| 参考文献 | `refs/chNN.bib` | キーは必ず `chNN-` で始める(章間の衝突防止) |
| 抽出メモ | `notes/notes-chNN.md` | 講義内容の忠実な抽出・使った資料のページ・裏取りした情報源・図の一覧 |

章ラベルは `\chapter{...}` の直後に必ず `\label{chap:chNN}`。他章への参照は番号を直書きせず `第~\ref{chap:chNN}~章` と書く(outline.md の章番号 NN を使う)。
ラベルも章ごとに名前空間を分ける: `fig:chNN-...`, `tab:chNN-...`, `sec:chNN-...`, `eq:chNN-...`。

## 2. 使える環境(main.tex で定義済み)

- `\begin{mokuhyo} \item ... \end{mokuhyo}` — 章冒頭の学習目標(3〜6項目)
- `\begin{teigi}{用語名}` — 定義(青)。初出の用語は **日本語(英語)** で書く
- `\begin{teiri}{タイトル}` — 定理・公式・重要事項・アルゴリズム(赤)
- `\begin{rei}{タイトル}` — 具体例(緑)
- `\begin{reidai}{タイトル}` 直後に `\begin{kai}` — 例題と解答(橙/灰)。途中の手順を省かない
- `\begin{point}[タイトル]` — 直感的な説明・ここがポイント(紫)
- `\begin{chuui}[タイトル]` — よくある誤解(茶)。該当箇所の本文中に置く
- `\begin{hosoku}[タイトル]` — 補足(ティール)。背景・発展・裏取りした詳細を入れ、`\cite{}` を付ける(「講義にない」とは書かない)
- `\begin{column}{タイトル}` — 歴史・実務・発展的話題(灰)
- `\begin{code}[language=SQL]{タイトル} ... \end{code}` — コード(listings)。言語は `SQL`, `Python`, `C`, `bash` など
- `\begin{mondai}{演習: 内容を表す見出し}` → `\begin{kaitou}{問N.Mの解答}` — 章末問題と解答
- 表は booktabs(`\toprule \midrule \bottomrule`)。縦罫線は使わない
- 数式は amsmath。`align`, `cases` など。番号付き式には `\label{eq:chNN-...}`

## 3. 章の構成(この順で)

1. `\chapter{章タイトル}` と導入文(なぜ学ぶのか・前の章とのつながり、4〜8行)
2. `mokuhyo`
3. `\section` 単位で講義内容を**再構成**(スライドの順に従う必要はない。理解しやすい順に)。
   流れの目安: 動機 → 定義 → point(直感) → teiri(性質・アルゴリズム) → rei(具体例) → reidai+kai(計算・手順)
4. 講義資料の内容は**すべて**扱う。スライドの例(テーブル・SQL・図)も落とさない
5. `\section{この章のまとめ}` — 章の要点(読み返すときに使う)を itemize で
6. `\section{章末問題}` — mondai を 5〜10 問。過去問・課題・ハンズオンの傾向を反映し、計算・記述・SQL作成などを混ぜる
7. `\section{章末問題の解答}` — 全問に kaitou で、採点基準になるくらい丁寧な解答と解説

分量の目安: 1章あたり A4 で 10〜16 ページ(tex で 450〜800 行)。講義の密度に合わせて増減してよい。
「スライドの言い換え」で終わらせず、なぜそうなるのか・どう使うのかを説明し、自分で例を作って理解を確かめさせる。

## 4. 図の方針(重要)

図を積極的に使う。目安は **1章あたり 4〜8 枚**。
1. **TikZ で描き直す**のが第一候補(ER図、木構造、グラフ、ブロック図、タイミング図、状態遷移、記憶階層、回路など)。
   清書品質で、文字は日本語でよい。`figures/chNN-*.tex` に分けて書き、本文から `\input`。
   pgfplots(グラフ)、forest(木)、circuitikz(回路)も使える
2. 描き直しが難しい図・写真・スクリーンショット・手書き板書は、スライドから切り出す:
   ```
   python3 ~/.codex/skills/textbook-builder/scripts/crop_fig.py <pdf> <ページ> figures/chNN-<名前>.png x0 y0 x1 y1
   ```
   座標はページに対する割合 (0〜1)。**切り出したら必ず PNG を画像として開いて**、見切れや余計なタイトル・ページ番号がないか確認する。
   **講義資料からは切り出さない**(TikZ・pgfplots で描き直す)。切り出しは、公開されている図を引用する必要がある場合に限り、キャプションに一般の出典(書名・論文・規格)を書く
3. ネット上の画像はダウンロードしない(TikZ で描き直す)
4. すべての図に `\caption` と `\label` を付け、本文で必ず「図~\ref{...} に示すように」と参照する
5. 図の位置は `[htbp]`。大きい表は `table` 環境に入れる
6. **tcolorbox の枠(rei, kai, kaitou など)の中に `figure`/`table` 環境は置けない**(Not in outer par mode になる)。枠の中では
   `\begin{center} ... \captionof{figure}{...}\label{...} \end{center}` を使う

## 5. ネットでの裏取り(必須)

- ウェブ検索で、その章の主要な定義・定理・数値・アルゴリズム・
  用語の英語表記を**少なくとも 5 件**確認する。元の資料と食い違う場合は、正しい内容だけを本文に書き、間違えやすい点は `chuui` に「よくある誤り」として書く(資料には触れない)
- 巨大なスキャン PDF(そのまま読めない)は `pdftoppm -r 80 -png -f N -l M <pdf> work/pages/<名前>` で画像にしてから開いて読む
- 講義資料にあるパスワード・認証情報・個人の連絡先は本文に載せない
- 講義資料だけでは説明が足りない箇所(証明の省略、背景、最新の状況、実務での使われ方)は補足して書く
- 信頼できる情報源を優先する: 標準の教科書、規格(ISO/ANSI/IEEE/RFC)、公式ドキュメント、大学の講義ノート、原論文。
  個人ブログは裏取りの補助にとどめる
- 日本人著者名は姓名が崩れるので `author = {{堀洋一} and {大西公平}}` のように1人ずつ波括弧で囲む
- 使った情報源は `refs/chNN.bib` に書き(`@book`, `@article`, `@online{..., url={...}, urldate={YYYY-MM-DD}}`)、本文で `\cite{chNN-...}`
- notes-chNN.md の末尾に「裏取りした事項 → 情報源 → 結果(一致/相違)」の表を残す

## 6. LaTeX の注意

- 日本語。句読点は「、。」で統一。英数字は半角
- 特殊文字 `% & # _ $ { } ~ ^ \` のエスケープ(本文中の「マーク&スイープ」のような & も)。下線付きの属性名は `\underline{sid}`
- SQL・コードは `code` 環境(中の特殊文字はエスケープ不要)。本文中の短いコードは `\texttt{}`(`_` は `\_`)
- `\verb` は tcolorbox の中で使わない
- `\section*` は使わない(目次に載せる)。`\subsection` まで、必要なら `\paragraph`
- main.tex にない新しいパッケージを使わない。必要なマクロは章の先頭で `\providecommand` する
- 書き終えたら、自分の章だけを入れた一時的な main を作ってコンパイルし、エラーを出さないことを確認する
  (手順は依頼文を参照)
