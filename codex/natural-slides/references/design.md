# デザイン基準

natural-slides原版から整理・改変した任意のスタイルプリセット。普遍的なデザイン規則ではない。ブランド、内容、可読性に合わせて調整する。

## 基本値

| 項目 | 16:9・1920×1080での出発点 |
| --- | --- |
| 背景・文字 | 白#FFFFFF、本文#3C3C3C、補助#6B6B6B |
| 主色 | 濃いグレー#2F3237。ブランド指定があれば置換 |
| 強調 | 黄色#F9DC72のマーカー。1ページの焦点を絞る |
| 書体 | 欧文・数字Montserrat、和文Noto Sans JP。未導入なら利用できる書体で再計測 |
| タイトル・本文・出典 | およそ44px・28〜32px・24px。実際の閲覧サイズで再確認 |
| 大きな数字 | 240〜300pxを出発点に、桁数・単位・意味の説明に合わせる |
| 枠・矢印 | 枠6〜9px、矢印5〜6px。通常の罫線まで太くしない |
| 余白 | 左右240px、箱内32px以上、縦間隔24/40/64pxを出発点にする |

キャンバスを変える場合は寸法を比例換算する。pxをそのままPPTのptに写さない。小さい表示や長文では密度を下げる。補助文字・出典も十分なコントラストを確保する。

## 骨組み

短いタイトル → 主張を伝えるリード → 一つの図・数字・主張 → 必要な出典。ロゴがあれば小さく置く。主役が小さく中央に固まったら、図の大きさや配置を再検討するが、空白を埋めるために装飾や架空データを追加しない。

このスタイルでは白地と太い輪郭を基本にし、影・グロー・全面グラデーションを常用しない。要点は短い言い切りで具体的に書く。客先の文体や引用の原文は維持する。

## 図を選ぶ

| 伝える関係 | 第一候補 | 誤読を防ぐ点 |
| --- | --- | --- |
| 順序・分岐 | 工程フロー・業務フロー | 矢印の方向をそろえ、分岐条件を付ける |
| 担当と受け渡し | スイムレーン | 担当名と境界を明示する |
| 段階・階層 | ピラミッド・ツリー | 上下の意味を明示。量でなければ面積を数値として扱わない |
| 反復 | サイクル | 開始条件・戻る条件が必要なら記載する |
| 選択肢・導入前後 | 比較図・表 | 同じ比較軸、対象、時点を使う |
| 二軸の位置 | マトリクス | 軸と評価根拠を示す。根拠なしの自社優位を作らない |
| 重なり・包含 | ベン図・包含図 | 集合関係を混同しない |
| 原因・分解 | フィッシュボーン・ロジックツリー | 仮説と検証済み原因を区別する |
| 予定 | タイムライン・ガント | 日付・期間・依存関係を実際の予定に合わせる |
| 人数・転換・内訳 | 大きな数字・ファネル・帯グラフ | 母数、単位、時点を残し、幅や割合を実データに合わせる |

図中に説明文を詰め込まず、ラベルは近くに置く。箱の内側へ文字を流し込み、語が途中で割れる場合は箱幅か改行を直す。図が二つ必要なら、比較自体が主題かを判断してから分割する。

数値グラフは供給・確認したデータだけから作る。棒の基準線、面積の比例、異なる軸の尺度を装飾の都合で変えない。単一の数値だけなら、その意味と比較条件を大きな数字の近くに添える。
