# やめること → 代わりに使うもの

禁止だけでは別の安全な形に逃げる。左の形に手が伸びたら、右の判断をしてから作る。画風（ブランドや`natural-slides`など）が指定されていれば見た目はそちらに従い、ここでは判断の中身だけを使う。

## 構成と文章

| やめること | 代わりに使うもの |
| --- | --- |
| 名詞だけのタイトル（「現状分析」「推進方針」） | 上段に章名（何の話か）、その下に述語まで書いた1文（何が分かったか・何をするか） |
| 抽象語で締める（「最適化」「推進」「強化」） | 誰が・何を・いつまでに・どれだけ、のうち分かっているものを書く |
| 1ページに役割を詰め込む | 主張1つにつき1ページ。詳細は別紙・Appendixへ |
| 主張と根拠を別のページに置く | 主張のページに、それを証明する図表を置く |
| 見出し＋補足を全カードで繰り返す | 数字を含んだ主張を1文で言い切る。同じことを言い直さない |
| 項目の語尾・表記がばらばら | 並列の項目は文型をそろえ、全体を並べて読み直す |
| もっともらしい数字で埋める | 入力にある数字と、そこから計算した数字だけ。不明は【要確認】 |
| とりあえず3つに分ける | 分類の軸を決め、重複と抜けを確かめた数で分ける（2つでも4つでもよい） |

## 形と配置

| やめること | 代わりに使うもの |
| --- | --- |
| 同じ大きさの箱を3つ以上並べる | 要素の関係（因果・順序・対比・主従・並列）を判定する。関係があれば図、主従があれば大きさに差をつける。同じ大きさは本当に対等なものだけ |
| 01・02・03の連番 | 本当に順序がある場合だけ番号。手順なら工程図、時期なら時間軸 |
| 一覧をそのまま表に流す | 前のページの枠組み（柱・章）で分けて並べる |
| 日付を表の列にする | 月の目盛りを持つ時間軸で描き、判断の節目（「3月末: 全社展開に進むか」）を入れる |
| 空白を装飾・アイコン・模様で埋める | 情報を足すか、ページをまとめる。空白は残してよい |
| 単語を汎用アイコンに置き換える（コスト→円マーク、最適化→歯車） | アイコンなしで言葉にする。使うなら全資料で同じ意味に固定 |
| 意味のない飾り線、端の帯、囲み枠、矢印 | 線を引くなら全ページ同じ場所に同じ意味で。矢印は実際の流れや因果があるときだけ |
| 主役を作るとき、まず見出しを巨大にする | 主役は根拠（数字、図、写真）の大きさとコントラストで作る |
| 素材写真、ロゴの透かし、背景の模様 | 写真は自社の実写だけ。なければ図と言葉で完成させる |

## 色とグラフ

| やめること | 代わりに使うもの |
| --- | --- |
| 目立たせたいものに同じアクセント色を撒く（見出し・線・アイコン） | アクセント色を「何にだけ」使うか1つ決め、全ページで固定 |
| 良い数字にも悪い数字にも同じ色 | 色の意味（自社/他社、増/減、判断箇所）を資料全体で1対1にする |
| 背景を順番に塗り分ける（交互、2トーン） | 本文の背景は統一。変えるのは表紙・章の扉・締めなど理由を言えるページだけ |
| グラフを全部着色する、最大値だけ強調する | 基本はグレー。タイトルの主張を証明する比較（合計・内訳・推移・差）を先に決め、そこだけに色 |
| タイトルの数字がグラフにない（タイトル「合計20時間」、グラフは内訳だけ） | タイトルの数字をグラフの中に書く。読み手に足し算をさせない |
| 色を「青を使わない」のように否定で指定する | 彩度・明度の範囲と「色名＋トーン＋近い実物」で指定する（例: 墨に近い濃紺、彩度低め） |

## ページの強さ

| やめること | 代わりに使うもの |
| --- | --- |
| 全ページ同じ強さ（どこにも主役がいて山場がない） | 強・中・静の枚数を先に決める。強は話の向きが変わる所と結論にだけ |
| 1枚ずつ別々に作る | 全ページを並べて、色の意味・背景・前ページとの対応を通しでそろえる |
