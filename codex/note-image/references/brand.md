# VERIMANTA ブランド指定（VERIMANTA関連の note のとき）

LPのデザインシステム（`verimanta-lp/index.html`）と揃える:

- 地: オフホワイト `#f7f8f7` / 面: `#fff`
- 文字: 墨色 `#16201e`
- アクセント: 深い青緑 `#0b6e5d` の1色のみ
- フォント: 見出し Zen Kaku Gothic New / 本文 Noto Sans JP / 欧文 Sora（Google Fonts）
- 角丸は使うなら10px（ボタン相当）か16px（カード相当）の2種のみ
- ロゴ・マスコット素材: `verimanta-lp/assets/`（透過PNG。ライト地には通常版か `-ink` 墨版）

コピー制約: 利益保証・「儲かる/勝てる」表現禁止。シミュレーションと実運用を区別。β版であることを画像内コピーでも偽らない。
