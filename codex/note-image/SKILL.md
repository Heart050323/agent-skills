# note-image — AI味のない note 用画像

note の見出し画像（1280×670px）と記事内挿絵を作る。判定基準は**誌面** — 紙の雑誌の1ページに刷られていて違和感がないか。誌面に載らない画像は完成ではない。

## サイズ

- 見出し画像: **1280×670px**（note推奨。中央がタイムラインで正方形に切り抜かれることがあるため、主役は中央に置く）
- 記事内挿絵: 幅1240px（表示幅620pxの2倍）で書き出す

## ルート選択

| ルート | 使うとき | 手段 |
|---|---|---|
| **A: 誌面カバー**（既定） | 概念・お知らせ・解説記事。タイポグラフィで語れるもの | HTML/CSS → ヘッドレスChromeでPNG化。AI生成を使わないのでAI味が構造的に出ない。日本語も正確 |
| **B: 写真・イラスト** | 具体的な被写体（場所・物・人・情景）が要るとき | AI生成。[references/ai-generation.md](references/ai-generation.md) を読んでから実行 |

迷ったらA。Bで作る場合も、文字入れはBの生成物にAの手法（HTML合成）で重ねる — 生成モデルに日本語を描かせない。

## Route A: 誌面カバー

1. **記事の主張を1行に圧縮する。** 見出し画像に載せる言葉は記事タイトルの複写ではなく、記事が言いたいことの最短形。完成基準: 載せる文言（主文+添え書き）が確定している。
2. **1280×670のHTMLを書く。** レイアウトは毎回変えてよいが、トンマナは固定:
   - 紙の白（#f7f8f7 系）を地にする。墨色（#16201e 系）の文字。アクセントは彩度低めの1色だけ
   - 書体は明朝（Zen Old Mincho / Shippori Mincho）か Zen Kaku Gothic New。Google Fontsは `<link>` で読み込む
   - 装飾は罫線・余白・文字組で作る。ピル型バッジ・グラデーション・影・発光は使わない
   - 注意: `mask-image` は file://+ヘッドレスで描画されない。使わない
   - VERIMANTA関連の記事なら [references/brand.md](references/brand.md) に従う
3. **PNG化する。**
   ```bash
   "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
     --headless --screenshot=cover.png --window-size=1280,670 \
     --hide-scrollbars "file:///絶対パス/cover.html"
   ```
   完成基準: PNGを開いて視認した。
4. **AI味チェック（下記）を全項目通す。** 1つでも該当したらHTMLを直して3からやり直す。
5. **成果物のパスを提示する。** 完成基準: PNGの絶対パスと、何の記事のどの位置（見出し/挿絵）に使うかをユーザーに伝えた。

## AI味チェック（全ルート共通の完成基準）

生成・作成した画像を必ず目視し、以下に1つも該当しないこと:

- 紫〜シアンのグラデーション地、発光、ネオン、レンズフレア
- ガラス質の3Dオブジェクト、浮遊する抽象球体、光る回路・脳・地球
- 過飽和・HDR調、プラスチックのような肌、画面全域にピントが合った不自然さ
- 握手するビジネスマン、ロボット、ホログラムUIなどのストック比喩
- 崩れた日本語・意味のない英文フェイクテキスト
- ダーク紺地＋蛍光アクセント＋枠付きバッジの組み合わせ（この職場では「AIで作った感」の記号）

代わりに: ライトな地、限定パレット、余白、具体的な被写体と光。

## Route B に入る前に

[references/ai-generation.md](references/ai-generation.md) を読む。バックエンドの選択・モデル別プロンプト型・AI味を出さないプロンプト規則が書いてある。読まずに生成しない。
