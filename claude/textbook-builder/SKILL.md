# 授業資料 → 教科書 ビルダー

1科目を1冊の教科書にする。章ごとの執筆は並列のサブエージェントに任せ、このセッションは
「資料の調査 → 章立て → 依頼 → 統合・ビルド → 品質確認」を担当する。

> **本文の方針(最優先・2026-11-24 改訂)**: 本は**自己完結した教科書**にする。元になった授業・資料・試験の存在を本文に一切出さない
> (「講義では」「講義資料 p.N」「過去問」「出典: 20XX 年度」「学生解答」などを書かない)。問題は「〜を理解するための演習」として出し、
> 資料の誤りは資料に触れずに正しい内容と「よくある誤り」で書く。詳細は `templates/STYLE.md` §0。
> 完成済みの本を新方針に直すときは `references/rewrite-guide.md` に従う。

```
SK=~/.claude/skills/textbook-builder
```

| ファイル | 用途 |
|---|---|
| `templates/main.tex` | プリアンブル(ltjsbook + tcolorbox の枠 + TikZ + listings + biblatex)。`{{...}}` を置き換えて使う |
| `templates/.latexmkrc` | LuaLaTeX + biber |
| `templates/STYLE.md` | 章の書き方・図・裏取りのルール。教科書フォルダにコピーしてエージェントに読ませる |
| `references/chapter-agent-prompt.md` | 章執筆エージェントへの依頼文テンプレート |
| `references/appendix-guide.md` | 演習付録(問題の解答と解説)と用語集の作り方 |
| `references/rewrite-guide.md` | 完成済みの本を新方針(自己完結・講義に言及しない)に書き直す手順 |
| `scripts/inventory.py` | 資料一覧(ページ数・テキスト有無・種別) |
| `scripts/extract.sh` | PDF → ページ区切り付きテキスト |
| `scripts/crop_fig.py` | PDF ページの一部を PNG 図に切り出す(PIL 不要) |
| `scripts/test_chapter.sh` | 1章だけのビルド確認 |
| `scripts/build.sh` | 全体ビルド + 指標(ページ数・未定義参照・Overfull・欠落ファイル) |

## 出力の構成

```
ナレッジまとめ/<科目>/
  main.tex  main.pdf  .latexmkrc  refs.bib(refs/*.bib を結合)
  outline.md  STYLE.md  PROGRESS.md
  chapters/  preface.tex ch01.tex … appendix-*.tex
  figures/   chNN-*.tex(TikZ) chNN-*.png(切り抜き)
  refs/      chNN.bib
  notes/     notes-chNN.md notes-exams.md
  work/      inventory.md extracted/ test-*/   (中間生成物。消してよい)
```

## 手順

### 0. 再開チェック
出力先に `PROGRESS.md` があれば読み、未完了の手順から再開する。

### 1. 調査
```
python3 $SK/scripts/inventory.py "<科目フォルダ>" "<出力>/work/inventory.md"
bash $SK/scripts/extract.sh "<出力>/work/extracted" <講義PDF...> <過去問PDF...>
```
- 同じ科目の資料が複数年度ある場合は、**最新年度の講義資料を軸**にし、古い年度は補足と過去問として使う
- 文字/頁が少ない PDF(スキャン・手書き)は Read で視覚的に読む。**1ページに複数スライドを刷ったスキャン(旧年度の配布資料など)は、このセッションで全ページを見て「ページ → 話題」の対応表を作り、outline.md の各章に `R14 p11–15` のように書き込む**(各エージェントが全ページを読む無駄を防ぐ)
- 講義が市販の教科書に沿っている場合(スライドに「教科書 p.N」「演習問題[x.y]」がある)は、書名を WebSearch で特定して STYLE.md の科目固有欄に書く
- 各講義の各ページの見出しを一覧にして(extracted の各ページ先頭行)、どこで話題が切り替わるかを確かめる
- 過去問は自分で全部 Read し、`notes/notes-exams.md` に問題文・出典・関連章・(あれば)解答の要点を書く。
  章のエージェントは出題傾向をここから知る

### 2. 章立て(outline.md)
- 講義の回ではなく**話題**で章を切る(1回の講義が2章にまたがってもよい)。目安は 12〜18 章、各 10〜16 ページ
- 各章: タイトル / 対応資料とページ範囲 / 主な内容 / 関連する過去問 を書く。全体を \part でまとめる
- 付録: 演習問題の解答と解説(元の問題を全部、分野別に)、記号・用語の和英対照表 など

### 3. 骨組み
- `templates/main.tex` をコピーし `{{SUBJECT}}`・`{{SUBTITLE}}`・`{{DESCRIPTION}}`(表紙の説明文 1〜2 文。本の内容だけを書き、講義・試験には触れない)・`{{DATE}}` などを置き換え、\part と `\chapinput{chNN}` を並べる
- 科目固有のマクロ(例 `\E`, `\Var`)があれば `% {{MACROS}}` の位置に追加
- `templates/.latexmkrc` と `templates/STYLE.md` をコピー。科目に合わせて STYLE.md に追記してよい
  (例: 「SQL は SQLite で動作確認」「回路図は circuitikz」)
- `chapters/preface.tex`(本書のねらい・構成・読み方・枠の凡例・前提知識。資料や授業の説明は書かない)を書く
- `PROGRESS.md` に手順と章ごとのチェックボックスを作る

### 4. 章の執筆(並列)
- `references/chapter-agent-prompt.md` を埋めて、1エージェント 1〜2 章で起動する(general-purpose)。対応資料・ページ・関連過去問は outline.md に正確に書き、依頼文では「outline.md の chNN の行をすべて取り込む」と指示すると短く正確になる。
  同時に 8 前後まで。各エージェントは自分の章のファイルしか書かない
- 付録(過去問の解説)は、過去問が1〜2回分ならこのセッションで書き、多い(3年分以上)なら別のエージェントに `references/appendix-guide.md` を渡して章と並行させる
- 統合時の後始末: 章ラベル `chap:chNN` の有無を確認、ch07 のように生成スクリプトから作られた章は PROGRESS.md に元ファイルを記録、エージェントがスクラッチパッドに置いた実験ファイルは work/ にコピー
- 完了報告が来たら PROGRESS.md にチェックを入れ、報告を短くメモする

### 5. 統合
```
python3 $SK/scripts/fix_bib_names.py "<出力>"   # 日本人著者名の統一
python3 $SK/scripts/fix_punct.py "<出力>"       # 句読点を「、。」に統一
cat refs/*.bib > refs.bib
bash $SK/scripts/build.sh "<出力>"
```
- エラーは file:line を見て直す。ラベル重複・未定義参照・欠落図を 0 にする
- `pdftoppm -r 50 -png -f N -l M main.pdf` で数ページずつ画像にして Read し、図の崩れ・空白ページ・はみ出しを確認する

### 6. 品質確認
- 網羅: 各講義 PDF の見出し一覧と目次を突き合わせ、落ちた話題がないか確かめる(notes を参照)
- 正確さ: 計算例・例題・章末解答を数問選んで自分で検算する。SQL・コードは実際に動かす(sqlite3, python3)
- 体裁: 用語の表記ゆれ、章間の重複、図番号の参照漏れ
- 必要なら レビュー用エージェントに「章 X–Y を読んで誤りを指摘(修正はしない)」を依頼し、指摘を反映する

### 7. 報告
- ページ数・章数・図の枚数・問題数・裏取りで直した点をまとめ、PDF を SendUserFile で渡す
- PROGRESS.md を「完成」にする

## 複数科目を続けて進めるとき(バッチ運用)
- 全科目の一覧と状態は `ナレッジまとめ/QUEUE.md`。上から順に `[ ]` の科目を選び `[~]` にしてから着手、完成したら `[x]`
- **使用量の管理(ユーザー指示)**: `mcp__ccd_session_mgmt__get_usage` で 5時間枠を確認する。
  - 科目の着手前とエージェント完了のたびに確認する
  - 85% を超えたら新しいエージェントを起動しない
  - 従量課金(extra usage)は使わない
  - 中断するときは PROGRESS.md に「どの章のエージェントが未起動/未完了か」を書き、QUEUE.md を `[~]` のままにする
- 目安: 1章を担当するエージェント1つで、5時間枠の約 1.5〜2% を使う。科目ごとに同時に走らせるのは 4〜5 エージェントまで(使用量を細かく管理するため)
- 同じ科目が複数学期のフォルダにある場合(電気機器学基礎、電力システム工学第一、高電圧工学など)は1冊にまとめ、QUEUE.md で両方を `[x]` にする

## 効率化のパターン(実績あり)
- **準備エージェント**: 資料が多い・スキャンが多い科目は、手順1〜2(資料の読み込み、ページ→話題の対応表 notes-sources.md、過去問メモ、outline.md、STYLE §7 追記)を
  1本のエージェントに任せる(「本文は書かない」と明記)。メインセッションの文脈を節約でき、使用量は5時間枠の約2〜3%
- **共通指示ファイル**: 章エージェントへの指示のうち共通部分を `work/agent-prompt-common.txt` に書き、各エージェントには
  「このファイルを読んで従え + 担当章 + 章固有の注意」だけを渡す。再開時もこのファイルを使う
- **記号の申し送り**: ある章の担当が記号・符号・数値例を決めたら、notes-chNN.md の先頭(「chNN への申し送り」)に書き、関連章の担当はそれを読んで合わせる
- **目安**: 13章+付録の1冊は、章エージェント5本で5時間枠の約25〜30%、週枠の約4〜5%を使う

## 資料が少ない科目
- **過去問しかない科目**(例: モーションコントロール): 過去問の全設問を読み、出題範囲を章立てにする。各章は標準的な教科書・原論文で構成し、
  標準的な文献で構成したことは notes に記録するだけで、本文には書かない。裏取りは各章10件以上。
  付録の演習で全問を解く。10章前後・1冊150〜250ページを目安にする
- **講義の一部だけ資料がない科目**(例: 量子力学II の後半): シラバスの項目とキーワードに沿って同じ方針で補う
- 資料が数ページ以下で過去問もない科目は QUEUE.md で `[-]` にしてユーザーに確認する

## 方針
- 元の資料の内容はすべて入れる。背景・発展は `hosoku`(出典付き)か `column` に入れる(本文で「講義にない」とは書かない)
- 図は TikZ・pgfplots で描き直す。講義資料から画像を切り出さない。ネットの画像はダウンロードしない
- ネット検索で主要な事項を必ず裏取りする。資料と食い違えば正しい内容だけを本文に書き、間違えやすい点は「よくある誤り」として書く
- 元の問題(試験・課題)で問われた範囲は、章末の演習と付録の演習で網羅する(本文では「演習」と呼び、年度や出典は書かない)

## 実績
- データベース工学(2026-11): 16章+付録、465ページ、TikZ 約125枚。章あたり 20〜45 ページになった(ユーザーはこの分量で了承)
- 情報セキュリティ(2026-11): 18章+過去問付録(5年分、別エージェント)、503ページ。10エージェント並列で約35分

## テンプレートの既知の修正(2026-11-19)
- 枠の見出しの \cite が濃い背景に溶ける → basestyle の fonttitle で `\hypersetup{citecolor=white,linkcolor=white,urlcolor=white}`(テンプレート反映済み)
- 番号付きの箱(teigi/teiri/rei/reidai/mondai)の本文中の `\label` が箱ではなく節の番号を指す → `\tcbfixlabel` を `before upper app` に入れた(テンプレート反映済み)。古い main.tex からコピーするときは両方入っているか確認する

## 運用のこつ(2026-11-20 追記)
- 準備エージェントは `references/prep-agent-prompt.md` を読ませ、科目名・資料フォルダ・出力先・科目固有の注意だけを渡す
- 章エージェントどうしの申し送りは SendMessage ではなく notes-chNN.md の先頭(「chNN への申し送り」「付録への申し送り」)に書かせ、読む側には「まだなければ他の章を先に書く」と指示する
- 使用量の目安: 章エージェント 10 本並行で 5時間枠を 10 分に約 13〜19% 使う。15 本だと 40 分弱で枠を使い切るので、同時に走らせるのは 10 本まで。枠が足りなくなりそうなら、最後に起動した科目のエージェントから止める(書きかけの tex は残るので「続きから」で再開できる)
- 用語集を「他章を待って書く」担当にすると待ち時間に枠を使うので、付録担当(全章完成後に起動)にまとめる
- 1 冊あたり週枠 4〜6%、5時間枠 25〜35%
