# 資料に基づくレポート作成

依頼と資料から、目的、読者、必要な長さ、提出形式、根拠の範囲を把握する。情報が足りなくても合理的に進められる部分は進め、結論に影響する不足だけを確認する。

主張と根拠が対応する構成を作り、資料に基づいて本文を書く。事実、解釈、提案を区別し、未確認の引用・数値・個人体験で穴を埋めない。結論の強さを証拠に合わせる。

読み直して論理の飛躍、重複、不要な定型表現を直す。全面リライトを毎回行う必要はない。文体の調整が必要なら [rewrite-human](../rewrite-human/SKILL.md)、出典検証が必要なら [verify-citations](../verify-citations/SKILL.md) の該当手順を使う。

指定された形式で納品する。ファイルの場合は保存先と確認範囲を示し、重要な未確認事項を明記する。文章を自然にするために、妥当な留保や著者の声を消さない。
